企画書：Michael Jackson Footsteps Beat Trainer – iPhone版（最適化版）

────────────────────────
1. プロジェクト概要
────────────────────────
タイトル：
　Michael Jackson Footsteps Beat Trainer（iPhone版）

コンセプト：
　iPhoneの強力なハプティクス（Taptic Engine）を使い、
　マイケル・ジャクソンのビートとステップを
　「指先で追い、身体で感じる」触覚ダンス体験アプリ。

目的：
　・マイケルのビートを触覚で体感する
　・ステップの軌跡を指で追うことで身体感覚として学ぶ
    ・音楽と振動が同期する“グルーヴ体験”を作る

ターゲット：
　・マイケル・ジャクソンのファン
　・ダンス初心者〜中級者
　・リズム感を鍛えたい人
　・音楽を触覚で感じたい人

対応デバイス：
　・iPhone（Taptic Engine搭載モデル）

────────────────────────
2. 体験フロー（UX）
────────────────────────
ステップ 1：起動
　・真っ暗な画面が表示される
　・「iPhoneを机に平置きしてください」と案内
　・ユーザーが平置きし、スタートジェスチャーで開始

ステップ 2：音楽スタート
　・ユーザーが個人的に所持しているマイケルの曲を読み込む
　・曲の再生開始と同時に、画面中央にスポットライトが点灯

ステップ 3：足跡の登場
　・スポットライト内に“マイケル風の足跡アイコン”が出現
　・曲のビートとステップに合わせて足跡が画面上を移動
　・左右の足、方向転換、スライドなどを抽象化して表現

ステップ 4：指で追従
　・ユーザーは指で足跡の軌跡をなぞる
　・タッチ位置・速度・タイミングをリアルタイムで取得
　・軌跡の一致度を判定し、正確なら足跡が光る

ステップ 5：ハプティクス（触覚ビート）
　・追従精度が一定以上なら、iPhoneがビートに同期して振動
　・振動パターン例：
    　- キック（ドンッ）：強い短い振動
    　- スネア（タッ）：鋭い振動
    　- ハイハット（チッ）：極短振動
    　- フィルイン：連続細振動
　・指先で“マイケルのビート”を感じながら軌跡を追う体験

ステップ 6：結果表示
　・追従精度（％）
　・タイミングのズレ（早い／遅い）
    ・軌跡のズレ（距離）
　・簡易コメント（例：「ビートは良い。方向転換が少し遅い」）

────────────────────────
3. 主要機能
────────────────────────
機能1：足跡パターン再生
　・曲に同期したステップ軌跡を再生
　・初心者向け／中級者向けの複数パターン

機能2：指の追従判定
　・タッチ座標・速度・タイミングを解析
　・軌跡との一致度をリアルタイムで判定

機能3：ビート連動ハプティクス
　・曲のテンポ（BPM）解析
　・キック／スネア／ハイハットの拍位置を抽出
　・ビートに同期した振動パターンを生成

機能4：結果フィードバック
　・追従精度
　・ズレ傾向
　・改善ポイントの簡易コメント

機能5：モード切り替え
　・ビート重視モード（振動強め）
　・ステップ重視モード（軌跡詳細）
　・観賞モード（操作なしで足跡＋ビートを眺める）

────────────────────────
4. 技術構成（iPhone版）
────────────────────────
・開発環境：Swift / SwiftUI / UIKit / Core Animation
・音楽解析：AVAudioEngine + BPM解析アルゴリズム
・ハプティクス：UIImpactFeedbackGenerator / CoreHaptics
・タッチ解析：UIKitのタッチイベント（座標・速度）
・足跡アニメーション：Core Animation / SpriteKit

────────────────────────
5. 発展アイデア
────────────────────────
・複数曲対応（ユーザーのライブラリから読み込み）
・ユーザー自身の軌跡を「マイケル風ステップ」として保存
・ARモードで床に足跡を投影し、実際に足で追従する拡張版
・ハプティクスの強弱をユーザーがカスタム可能

────────────────────────
6. 核となる体験
────────────────────────
・指で足跡を追う → 視覚的にステップを学ぶ
・ビートの振動を感じる → 触覚でグルーヴを学ぶ
・音楽が流れる → マイケルの世界観に没入する

三位一体の体験によって、
「マイケルのビートを身体で刻む感覚」を再現する。
