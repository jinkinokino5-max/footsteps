# 実機体験マニュアル（His Footsteps v2 を iPhone で試す）

最新ビルドを iPhone に入れて、実際に体験するまでの手順書。
初回セットアップ（AltServer/AltStore の導入）がまだなら、先に `draft/Phase0_セットアップ手順.md` を参照。

---

## 手順1：最新ビルドを入手する

1. GitHubリポジトリ → 上部タブ「Actions」
2. 一番上（最新）のワークフロー実行をクリック
   - 緑のチェック＝ビルド成功。赤い×＝失敗（インストールできる .ipa は無い）
3. 実行詳細ページ下部の「Artifacts」から `HisFootsteps-unsigned-ipa` をダウンロード
4. zipを展開して `HisFootsteps-unsigned.ipa` を取り出す

## 手順2：iPhoneへインストールする

1. iPhoneとPCを同じWi-Fiに繋ぎ、PCでAltServerを起動
2. iPhoneのAltStore →「マイApp」→ 左上「+」
3. `HisFootsteps-unsigned.ipa` を選択
4. ホーム画面に「His Footsteps」が追加される（既に入れていれば上書き更新）

---

## 手順3：**最初にこれをやる**（振動を最大にする準備）

**この2つを確認しないと、v2でも振動は弱いままです。**

| 確認すること | どこ |
| --- | --- |
| **低電力モードをオフにする** | 設定 → バッテリー → 低電力モード **オフ**<br>（オンの間、iPhoneのTaptic Engineは完全に止まります） |
| **システムハプティクスをオンにする** | 設定 → サウンドと触覚 → システムの触覚 **オン** |

さらに、**iPhoneを机に平置きして、手のひらか指を面で置く**こと。
手に持って宙に浮かせていると振動が逃げます。机に置くと机が鳴って体感が数段変わります。

## 手順4：アプリを開く

### 4-1. オンボーディング（真っ暗な劇場）

- 中央の円が **1.15秒ごとに鼓動**します。これが基準の触感です。
- 円をタップすると「キメ」の一撃（一番強い振動）が鳴ります。ここで強さを確かめてください。
- 低電力モードや非対応端末なら、ここに赤い警告が出ます。
- 「ステージへ」で選曲画面。

### 4-2. 選曲画面（楽屋）

| 項目 | 内容 |
| --- | --- |
| **MODE** | BEAT（ビート重視）／STEP（ステップ重視）／WATCH（観賞） |
| **HAPTIC POWER** | そっと／標準／**強烈**（初期値・推奨）<br>「試す」でその場でキックを鳴らして比べられます |
| **TRACK** | 曲の一覧。「曲を追加」で自分のMP3を取り込めます |
| **FINE TUNE** | 振動のタイミング微調整（±60ms）／低音ブースト |

モードの違い：

| モード | 内容 |
| --- | --- |
| BEAT | 閃光と粒子が最大。判定は甘め。とにかく浴びたいとき |
| STEP | 次の3歩がゴーストで先に見える。判定は厳密。練習向け |
| WATCH | 指の操作なし。足跡とビートをただ眺める |

### 4-3. 曲を追加する（自分のマイケルを入れる）

**方法A（アプリ内・おすすめ）**
1. 選曲画面の「**曲を追加**」をタップ
2. iPhoneの「ファイル」アプリが開くので、mp3 / m4a / wav を選ぶ
   （事前にiCloud DriveやDropbox等からiPhoneに保存しておく）
3. 一覧に追加される。ゴミ箱アイコンで削除できる

**方法B（PCから直接）**
- iPhoneをPCに繋ぎ、ファイル共有の「His Footsteps」に曲をドラッグ

**方法C（ビルドに内蔵）**
- `Resources/Music/` に置いてビルドし直す

### 4-4. 「踊る」を押す

1. 初回だけ **解析** が走ります（3〜5分の曲で数秒〜十数秒）。
   波形が左から埋まり、「テンポと拍の位置を追跡しています」等の表示が進みます。
   → 2回目以降はキャッシュから一瞬で始まります。
2. **4カウント**（4・3・2・1）が振動と一緒に刻まれます。この間に指を画面へ置いてください。
3. 曲がスタート。

### 4-5. 本番でやること

- **指を画面に置いたまま、光る足跡（金色）を追いかける**。離さないこと。
- 足跡は拍ごとに移動します。移動の仕方は種類で違います。
  - 踏み込み：素早く動いてピタリと止まる
  - 滑り（ムーンウォーク）：拍いっぱいを使って等速で流れる
  - 溜め：ギリギリまで動かず一気に到達する
  - スピン／つま先立ち／フリーズ：8小節に一度の見せ場
- **次に踏む場所は、白い破線のゴーストで先に見えています。** 破線のアーチが今の足からそこへ繋がります。
  BEATモードは1歩先、STEPモードは3歩先まで。
- 指が足跡に近いほど、指と足を結ぶ**金の糸**が濃くなります。
- 判定は **PERFECT / GREAT / GOOD / MISS**。PERFECTだと小さな確認振動が返ります。
- 画面下に COMBO と SCORE。
- **繋げるほど舞台が明るくなります。** 床のグリッドが燃え、スポットライトが強くなり、
  粒子が増える。45コンボで表示が **FEVER** に変わります。
- 右上の■でいつでも終了。

### 4-6. 結果

RANK（S+〜D）、スコア、精度、最大コンボ、判定の内訳、
そして **COACH**（何がズレているか・次に何を直すか）が出ます。
「もう一度踊る」で同じ曲を再挑戦（振り付けは同じ曲なら毎回同じです）。

## 体験のチェックポイント（v2で何が変わったか）

実機で以下が成立しているか見てください。ここがv1との差です。

| 見るところ | 期待する体験 |
| --- | --- |
| キックの触感 | 「カチッ」ではなく「**ズドン**」。低く、重く、余韻がある |
| スネアの触感 | キックとはっきり違う。鋭く弾ける「パンッ」 |
| 拍と拍の間 | 完全な無音ではなく、低いうねりが続いている（＝グルーヴベッド） |
| 小節頭のキメ | 8小節に1回くらい、全身に来る一撃＋画面が白く飛ぶ |
| 音とのズレ | 曲が長くなってもズレていかない（曲頭と曲尾で同じ精度） |
| 足跡の動き | ただの移動ではなく、踏む／滑る／溜める／回るの違いが見える |
| 画面 | 床が奥へ伸び、照明が首を振り、キックで画面が揺れ、床を光の帯が走る |
| 奥行き | 奥の足跡は小さく、手前の足跡は大きい。床のパースと一致している |
| コンボ | 繋げるほど舞台全体が明るく熱くなっていく |

**もし「音とズレている」と感じたら**：選曲画面の FINE TUNE →「振動のタイミング」を動かしてください。
振動が遅れて感じるなら右（＋）へ。ワイヤレスイヤホンの遅延は自動補正していますが、体感には個人差があります。

## うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| **振動が弱い／しない** | ① 低電力モードがオフか ② 設定→サウンドと触覚→システムの触覚がオンか ③ HAPTIC POWERが「強烈」か ④ iPhoneを机に平置きしているか |
| 指を動かしても反応しない | 画面のどこでもドラッグできます。WATCHモードになっていないか確認 |
| 曲が一覧に出ない | 対応形式は mp3 / m4a / wav / aac / aif / caf。それ以外は取り込めません |
| 解析が失敗する | 曲ファイルが壊れている可能性。別の曲で試す |
| テンポが違う気がする | 76〜152BPMに正規化しています。倍テンポの曲は半分の拍で刻みます（足で踏める速さに揃えるため） |
| アプリが7日後に起動しない | 無料Apple IDの署名切れ。手順2を再実行 |

## まだ無いもの（正直に）

- ARモード（床に足跡を投影）
- 自分の軌跡を保存して見返す機能
- オンラインのランキング
