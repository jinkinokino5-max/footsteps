# 実機体験マニュアル（His Footsteps を iPhone で試す）

このドキュメントは、最新ビルドを iPhone にインストールしてから、実際にアプリを触って体験するまでの手順書。
初回セットアップ（AltServer/AltStoreの導入）がまだの場合は、先に `draft/Phase0_セットアップ手順.md` を参照。

## 前提条件
- Windows PC と 実機iPhone（Taptic Engine搭載モデル）が用意できていること
- AltServer（Windows版）をインストール済みで、iPhoneにAltStoreが入っていること（未実施なら `draft/Phase0_セットアップ手順.md` を先に実施）
- iPhoneとPCが同じWi-Fiに接続できること（再署名・インストールに使用）

## 手順1：最新ビルドを入手する
1. GitHubリポジトリのページ → 上部タブの「Actions」を開く
2. 一番上（最新）のワークフロー実行をクリック
   - 実行名の右側に緑のチェックマークが付いていればビルド成功（赤い×は失敗＝インストールできる.ipaは無い）
3. 実行詳細ページの下の方にある「Artifacts」欄から `HisFootsteps-unsigned-ipa` をダウンロード
4. ダウンロードしたzipを展開し、`HisFootsteps-unsigned.ipa` を取り出す

## 手順2：iPhoneへインストールする
1. iPhoneとPCを同じWi-Fiに接続し、PC側でAltServerを起動しておく
2. iPhoneのAltStoreアプリを開き、「マイApp」タブ → 左上の「+」をタップ
3. 手順1で取り出した `HisFootsteps-unsigned.ipa` を選択
4. インストールが完了すると、ホーム画面に「His Footsteps」アプリが追加される
   - 既に入れている場合は上書きインストールになり、そのまま最新版に更新される

## 手順3：アプリを開いて体験する
アプリを開くと、次のような画面・操作ができる。

### 3-1. 画面の見方
- 上部：アプリタイトルと、モードを切り替えるセグメントボタン（**ビート重視 / ステップ重視 / 観賞**）
- 中央：足跡が動く「ステージ」エリア（このエリアを指でなぞって遊ぶ）
- その下：「ハプティクスをテスト」ボタン（単発の振動確認用）
- さらに下：内蔵曲の一覧と再生コントロール

### 3-2. まず振動だけ確認する
1. 「ハプティクスをテスト」ボタンをタップ
2. 一回だけ「ドンッ」と振動すればOK（ハプティクス非対応の端末では赤字で警告が出る）

### 3-3. 曲を選んで拍を解析する
1. 「内蔵曲」一覧から好きな曲をタップして選択（選択中はチェックマークが付く）
2. 「拍を解析」ボタンをタップ（曲の長さに応じて数秒かかる。「解析中...」の表示が消えたら完了）
3. 完了すると「推定BPM」と「検出した拍の数」が表示される

### 3-4. モードを選ぶ
画面上部のセグメントボタンで、体験のスタイルを選べる。
| モード | 振動の強さ | 指でなぞる判定 |
|---|---|---|
| ビート重視 | 強め | あり |
| ステップ重視 | 標準 | あり |
| 観賞 | 中間 | なし（操作不要、眺めるだけ） |

### 3-5. ビートに合わせて再生する（メイン体験）
1. 「ビートに合わせて再生」ボタンをタップすると、曲の再生・振動・足跡アニメーションが同時に始まる
2. **「ビート重視」「ステップ重視」モードのとき**：画面中央のステージ内を、動く足跡（オレンジ色）に指を重ねるように追いかけてなぞり続ける
   - 指を置いた位置は青い丸で表示される
3. **「観賞」モードのとき**：操作は不要。曲・振動・足跡の動きをそのまま眺める
4. 曲（拍データ）の再生が終わると、自動的に結果パネルが表示される（観賞モードでは表示されない）
   - **追従精度**：足跡にどれだけ指を合わせられたかのスコア（%）
   - コメント：精度に応じたひとことフィードバック
   - タイミングのズレ：全体的に「早め」「遅れ」「よく合っている」のコメント
5. 「停止」ボタンでいつでも途中終了できる

### 3-6. もう一度試す
- 「拍を解析」済みの曲であれば、「ビートに合わせて再生」を何度でも押し直して良い（毎回、結果はリセットされる）
- 別の曲を試す場合は、内蔵曲一覧から選び直す→再度「拍を解析」

## 現時点での制限（正直な注意点）
- 拍検出はエネルギーピーク検出による簡易アルゴリズムのため、曲によっては拍がずれて検出されることがある
- 追従精度・タイミングのズレ判定は「割り切った精度」の簡易実装であり、本格的なモーションキャプチャ相当の精度ではない
- ARモード（床に足跡投影）はまだ未実装
- 無料Apple IDで署名したアプリは7日で失効する（`draft/Phase0_セットアップ手順.md` の「注意点：7日ごとの再署名」を参照）

## うまく動かないとき
| 症状 | 確認すること |
|---|---|
| 振動しない | 「ハプティクスをテスト」で赤字の非対応警告が出ていないか確認。iPhone本体のサイレントモード・集中モードは振動には影響しないはずだが、念のため確認 |
| 曲が一覧に出ない | 最新の.ipaを入れ直したか確認（`Resources/Music` に曲が入っているビルドか） |
| 「拍を解析」が失敗する | 曲ファイル自体が壊れている可能性。別の曲で試す |
| アプリが7日後に起動しない | 署名切れ。手順2を再実行してインストールし直す |
